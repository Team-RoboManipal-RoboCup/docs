# Autonomy

The autonomy system provides high-level mission management, referee box communication, and task planning for RoboCup Smart Manufacturing League (SML) competitions. 

Operating above the navigation and manipulation layers, the global task planner translates competition orders (produce and recycle) into ordered action sequences using classical automated planning frameworks.
